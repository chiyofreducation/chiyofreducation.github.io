# Chiyo

Vidéos et activités interactives pour apprendre, du collège et au-delà.

- Chaîne YouTube : https://www.youtube.com/@ChiyoFrEducation

## Organisation du site

- `index.html` : page d'accueil (une carte par matière)
- `histoire-6e/index.html` : liste des activités d'histoire 6e
- `histoire-6e/episode-1a.html` : Épisode 1A « Mesurer et compter le temps »

Chaque activité est un fichier autonome : aucune donnée n'est envoyée,
le résultat est seulement téléchargé par l'élève sous forme de badge PDF.
