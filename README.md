## Confidentialité et sécurité

- Site statique : aucun compte, aucun serveur, aucune base de données.
- Aucune donnée n’est envoyée : le prénom de l’élève reste dans son navigateur
  et sert seulement à écrire son nom sur le badge PDF.
- Ni cookies, ni publicité, ni outil de statistiques.
- Chaque page est autonome (voix, images et outils intégrés) et interdit le chargement
  de contenus extérieurs.
